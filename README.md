# 원기옥 AR

카메라 앞에서 두 손을 올려 에너지를 모으고, 100%가 되면 손을 내려 원기옥을 발사하는 브라우저 AR 데모입니다.

## 실행 방법

카메라 권한은 안전한 주소에서만 동작합니다. 로컬에서는 `localhost` 서버로 열어주세요.

```powershell
node dev-server.cjs 5173
```

브라우저에서 `http://127.0.0.1:5173`을 열면 됩니다.

## GitHub Pages 배포

1. GitHub 저장소의 `Settings`로 이동합니다.
2. `Pages` 메뉴에서 배포 소스를 현재 브랜치의 루트 폴더로 선택합니다.
3. 배포된 Pages 주소로 접속한 뒤 카메라 권한을 허용합니다.

별도 빌드 과정은 없습니다. 루트의 `index.html`이 그대로 배포됩니다.
